# REU CONNECT — подготовка Telegram Mini App

## Что изменено
- Подключён официальный Telegram Web Apps SDK.
- При открытии внутри Telegram вызываются `ready()` и `expand()`.
- Устанавливаются фирменные цвета шапки и фона Telegram Web App.
- Добавлены CSS-правила для viewport и безопасных областей мобильного интерфейса.
- Обычный браузерный режим сохранён: если Telegram SDK недоступен, сайт работает как раньше.

## Что не менялось
- `server.js`, API, регистрация по email, встречи, чаты и модерация.
- Структура базы данных.
- Никакая Telegram-авторизация не включена: выбранный способ входа — email.

## Публикация
1. Сначала сделайте резервную копию текущего проекта и базы данных.
2. Замените `public/index.html` файлом из этой сборки.
3. Добавьте `.gitignore`, чтобы не публиковать `data/db.json`, токены и `.env`.
4. Закоммитьте изменения в GitHub и дождитесь успешного деплоя Render.
5. Проверьте сайт в обычном браузере.
6. Создайте бота через @BotFather.
7. В настройках бота добавьте Mini App URL `https://connect-nvpk.onrender.com/`.
8. Настройте Menu Button и Main App (Launch App), используя один и тот же HTTPS URL.
9. Откройте приложение из Telegram на iOS и Android и проверьте формы, нижнюю навигацию, чаты и клавиатуру.

## Важная безопасность
- Не загружайте `data/db.json` в публичный GitHub.
- Перед публичным запуском отзовите ранее выданные токены сессий и смените `MOD_CODE`.
- Текущая регистрация по email не подтверждает владение почтой. Это ограничение исходного приложения, оно не исправлено в этой Mini App-адаптации.
- Telegram SDK на клиенте не является механизмом аутентификации. В этой версии Telegram используется только как среда запуска и интерфейсная интеграция.

## Настройка BotFather
- Создайте бота через `/newbot`.
- Настройте описание и изображение.
- Установите Menu Button через `/setmenubutton` и укажите URL приложения.
- Настройте Main App через настройки бота в BotFather и укажите тот же URL.
- Токен бота храните только в защищённых переменных окружения, если позднее появится серверная интеграция с Bot API.
