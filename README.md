# Коннект — сайт с сервером

Сервер на чистом Node.js (18+), без установки библиотек. Сайт лежит в `public/index.html`, данные хранятся в `data/db.json`.

## Запуск на своём компьютере
1. Установите Node.js (nodejs.org, версия LTS).
2. В папке проекта выполните: `node server.js`
3. Откройте http://localhost:3000
4. В консоли будет напечатан **код модератора**. Свой задайте так: `MOD_CODE=мойкод node server.js` (Windows PowerShell: `$env:MOD_CODE="мойкод"; node server.js`).

## Что умеет
- Регистрация и вход по почте (пароль не нужен). Счётчик студентов виден в шапке сайта и на странице входа.
- Приглашения создаются и видны всем в реальном времени, «Я с вами!» работает.
- Чаты настоящие: общий и у каждой встречи (видят только участники). Обновление раз в 2,5 секунды.
- Модератор: **7 быстрых нажатий на логотип «Коннект»** (в шапке, после входа) → ввод секретного кода. Код хранится только на сервере. Модератор видит вкладку «Модерация»: аккаунты, встречи, жалобы, счётчики; может удалять встречи, сообщения, аккаунты.

## Выложить в интернет (чтобы работала ссылка)
Подойдёт любой хостинг для Node.js (Render, Railway, Timeweb Cloud, Beget VPS и т. п.):
- команда запуска: `node server.js`
- переменная `MOD_CODE` = ваш секретный код
- переменная `PORT` хостинг задаёт сам
- чтобы аккаунты не пропадали при перезапуске, подключите постоянный диск и укажите `DATA_DIR` на него. На бесплатных тарифах диск обычно временный: данные сбросятся.

Если сайт остаётся на GitHub Pages, а сервер отдельно: в конце `public/index.html` в строке `window.CONNECT_API=""` впишите адрес сервера, например `"https://connect.example.com"`.

## Ограничения (честно)
- Вход только по почте без подтверждения: кто знает чужую почту, может войти под ней. Для учебного проекта это допустимо; для реального запуска нужна ссылка-подтверждение на почту.
- Ограничения частоты запросов есть, но это не полноценная защита.
