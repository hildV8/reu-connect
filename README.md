# REU CONNECT 2.0

Студенческая платформа на Node.js + HTML/CSS/JavaScript. Без React и без дополнительных npm-зависимостей.

## Возможности

- Регистрация и вход по email.
- Персональная лента: мероприятия, новости и рекомендации сообществ.
- Каталог сообществ: поиск, категории, создание, вступление и выход.
- Мероприятия: публикация, участие, список участников и чаты встреч.
- Профиль студента: факультет, курс, описание, интересы, навыки, достижения и проекты.
- Telegram-уведомления: мероприятия, новости, сообщения в чатах и напоминания — после настройки Bot API.
- Панель модератора.
- Работа в обычном браузере и в Telegram Mini App.

## Локальный запуск

1. Установите Node.js 18 или новее.
2. В корне проекта выполните `node server.js`.
3. Откройте `http://localhost:3000`.
4. Для собственного кода модератора задайте `MOD_CODE` в переменных окружения.

## Данные и Render

Данные хранятся в `data/db.json` (или в папке, указанной в `DATA_DIR`). На Render для сохранения пользователей между деплоями и перезапусками нужен Persistent Disk. Сначала сделайте резервную копию действующей базы; затем проверьте/подключите диск и направьте `DATA_DIR` на его mount path. Не заменяйте базу пустым файлом и не добавляйте `db.json` в GitHub.

## Telegram-уведомления

Для реальной отправки сообщений добавьте в Render Environment `BOT_TOKEN`, `BOT_USERNAME` (без `@`) и `BOT_WEBHOOK_SECRET`, затем настройте Telegram webhook на `https://connect-nvpk.onrender.com/api/telegram/webhook` с тем же секретом. Подробные шаги находятся в `README_REU_CONNECT_2_0.md`. Токен бота не включён в исходники.

## Публикация изменений

В GitHub замените `server.js` в корне и `public/index.html` в папке `public`. Не загружайте `data/db.json`, `.env` и секреты. Перед деплоем обязательно проверьте постоянное хранилище Render.
