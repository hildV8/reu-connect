# REU CONNECT 2.0 — обновление четырёх модулей

Основа: существующий проект на Node.js + HTML/CSS/JS. Фреймворки и новые npm-зависимости не добавлялись.

## Что реализовано

### 1. Персональная лента
- Единая страница «Лента».
- Ближайшие встречи и существующие фильтры мероприятий.
- Лента новостей/объявлений, публикуемых модератором.
- Блок рекомендаций сообществ. Сортировка учитывает интересы из профиля и размер сообщества.

### 2. Каталог сообществ
- Каталог с поиском по названию, описанию и категории.
- Стартовые тематические направления: карьера, бизнес, наука, спорт, творчество. Это направления для поиска единомышленников, а не заявления об официальных подразделениях РЭУ.
- Создание сообщества пользователем.
- Вступление и выход из сообщества; счётчик участников.

### 3. Telegram-уведомления
- Настройки четырёх категорий уведомлений в профиле.
- Привязка Telegram к существующему аккаунту через одноразовую deep-link ссылку и команду `/start` бота.
- Отправка уведомлений о новых мероприятиях, новостях, сообщениях в чатах встреч и напоминаний о мероприятиях.
- Реальная отправка требует настроить переменные окружения и webhook (см. ниже). Токен бота не включён в архив.

### 4. Развитый профиль
- Сохранены поля имени, факультета/направления и курса.
- Добавлены редактируемые поля «Обо мне», «Интересы», «Навыки», «Достижения и проекты».
- Новые поля необязательные: существующие записи пользователей сохраняют совместимость.

## Какие файлы обновить в GitHub

Из этой сборки замените только:
1. `server.js` в корне репозитория.
2. `public/index.html` в папке `public`.

Не заменяйте и не загружайте `data/db.json`, `.env`, токен бота и другие секреты. Не загружайте локальную тестовую базу из папки проверки.

## ВАЖНО: постоянное хранение пользователей на Render

Текущий сервер хранит данные в `data/db.json`. На Render файловая система без подключённого Persistent Disk может сбрасываться при новом деплое/перезапуске. Перед публикацией:

1. В Render проверьте, подключён ли Persistent Disk к сервису.
2. Если диск уже есть, не меняйте его mount path и текущее значение `DATA_DIR`.
3. Если диска нет, сначала сделайте доступную резервную копию текущей базы, затем подключите Persistent Disk (например, mount path `/var/data`) и задайте `DATA_DIR=/var/data`.
4. Только после проверки пути и резервной копии выполняйте деплой.

Не создавайте новую пустую базу поверх прежней и не коммитьте `db.json` в GitHub.

## Telegram Bot API — включение уведомлений

Добавьте в Render Environment:

- `BOT_TOKEN` — токен от BotFather (хранить только в Render, не в коде и не в GitHub).
- `BOT_USERNAME` — username бота без `@`.
- `BOT_WEBHOOK_SECRET` — случайная строка из латинских букв и цифр, не менее 32 символов.

После успешного деплоя один раз настройте webhook запросом к Telegram Bot API `setWebhook`, указав URL:

`https://connect-nvpk.onrender.com/api/telegram/webhook`

И передайте то же значение `BOT_WEBHOOK_SECRET` в параметре `secret_token`. Сам запрос выполняйте локально или через защищённый инструмент, подставляя токен и секрет из своих переменных окружения; не отправляйте их в чат.

Пользователь подключает Telegram в разделе «Профиль → Уведомления», нажимает «Подключить Telegram», затем нажимает Start в боте и возвращается в приложение, чтобы обновить статус.

## Данные пользователей

В сборке нет скрипта, который добавляет или удаляет пользователей. `/api/stats` по-прежнему считает реальные пользовательские записи из базы данных (`users`, исключая системную запись команды). Никакие фиктивные аккаунты не создаются.

## UI update: theme switch and recommendations

- Added a light/dark theme switch in the top bar. The selected theme is stored in browser localStorage under `connect_theme` and is shared by the regular site and Telegram Mini App in the same browser context.
- Added a dedicated **Рекомендации** navigation item and page. Recommendations are loaded from the existing `/api/feed` endpoint; the events feed remains available separately.
- Kept the existing navigation destinations, profile, events, chats, moderation, communities, and Telegram settings.
- Added clearer spacing and page hierarchy around recommendations and the feed.

No database file or user records are included in this release archive. Deploy the updated `public/index.html` together with the existing REU CONNECT 2.0 server files.
